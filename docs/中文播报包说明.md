# 中文播报包（已部署）

## 结论：技术路线已确定

**路线 B（`sound_library` 采样重定向）实测生效**，这是最干净的一条：

- ✅ 不动任何原版文件
- ✅ 不需要任何启动参数
- ✅ 不污染游戏根目录
- ✅ 卸载就是删掉 `extensions\x4_annc_cn\` 一个目录

原理：`libraries/sound_library.xml` 里每个语音场合登记着 `<sample start="voice\10002\normal"/>`，
这是**权威的加载目录**。扩展用 `<diff><replace>` 把它改成
`extensions\x4_annc_cn\voice\10002\normal`，引擎就会去扩展里取音频。

**顺带确认的技术细节**：引擎**直接采用 sample 里写的路径**，不会自动加 `-l044` 语言后缀
（探针里只放了不带后缀的 `voice/...` 路径，就成功播出了）。

**为什么路线 A（同名覆盖 `voice-l044/...`）不行、而 B 行**：覆盖对音频这条查找路径无效
（尽管对脚本/贴图/UI 有效 —— starwarsmod 就覆盖了 589 个基础文件）。
B 之所以能绕开，是因为它指向的是一个**全新的、只存在于扩展里的路径**，不存在覆盖优先级问题。

## 怎么验证

**改完之后游戏已经在运行的话，必须重启游戏**（扩展的 dat 在启动时挂载）。

重启后：

1. **飞船电脑**：按 `Shift+A` 开自动驾驶、`Shift+D` 请求停靠，或者干脆被打一下 ——
   会听到「自动驾驶已激活」「护盾危急」「船体受损」这类中文提示。
2. **空间站广播**：停靠任意空间站，站内会循环播放中文公共广播，
   比如「警卫提醒所有游客，请时刻看管好自己的行李。」

> 有一部分台词本来就是**拼接片段**（原版也是分段念的），单独听会略突兀，例如
> 「来自」「来电」。这是原版的设计，不是 bug。

## 想扩大范围

改 `plans/annc_cn_final.json` 里的 `targets` 即可，流水线会自动：

1. 从 `t/0001-l086.xml` 取该 page 每条台词的中文原文
2. 批量 TTS 合成 → 转成 X4 格式的 ogg
3. 铺到 `voice/<page>/<context>/<line>.ogg`
4. 为对应 sound id 生成 `<replace>` 重定向
5. 打包成 `ext_01.cat/dat`

各 page 的台词条数见 `docs/voice_pages.csv`。可选范围举例：

| 想加什么 | page | 追加条数 |
|---|---|---|
| 星系名播报 | `20005` | 392 |
| 船名播报 | `20101` | 426 |
| 空间站名播报 | `20102` | 147 |
| 全部 NPC 通用对话 | `10101`–`10507` 等 | 约 25 000 |

## 卸载

删掉 `extensions\x4_annc_cn\` 即可，原版语音毫发无损。
